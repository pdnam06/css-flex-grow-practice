Phân phối không gian với flex-grow

Trong 5 Flex Item, ô thứ hai nhận toàn bộ phần không gian còn trống.

Ví dụ: flex-grow ở Item 2

Item 1grow: 0
Item 2grow: 1
Item 3grow: 0
Item 4grow: 0
Item 5grow: 0

Kết quả quan sát

  • Container rộng 800px và có gap 10px giữa các ô.
  • Mỗi Item có kích thước cơ sở 100px; mặc định flex-grow bằng 0.
  • Phần không gian còn trống: 800 − (5 × 100) − (4 × 10) = 260px.
  • Item 2 dùng flex-grow: 1 nên rộng 100 + 260 = 360px; bốn Item còn lại rộng 100px.
  • flex-grow phân phối không gian còn trống, không trực tiếp quy định tỉ lệ chiều rộng cuối cùng.

CSS chính

.container {
    display: flex;
    width: 800px;
    gap: 10px;
}

.item {
    box-sizing: border-box;
    flex-basis: 100px;
    flex-grow: 0;
}

.item:nth-child(2) {
    flex-grow: 1;
}

Trên điện thoại, vuốt ngang trong khung ví dụ để xem đủ 5 ô. Kích thước khung được giữ nguyên để dễ so sánh.
